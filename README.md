# Consultant Plus Selenium Test (Java + TestNG + Allure)

Автоматизированный UI‑тест для сайта КонсультантПлюс, реализующий сценарий «HappyPath»:
поиск по запросу «Налоговый часть», открытие «Налоговый кодекс РФ (часть вторая)»,
переход по ссылке на абзац в статье 145 и проверка результата.

## Требования

- JDK 17+ (в проекте используется Java 17+, maven-compiler-plugin настроен на 25)
- Maven
- Google Chrome последней версии
- Доступ к интернету (для загрузки драйвера через WebDriverManager и работы с сайтом)
- PowerShell (рекомендуется для стабильного запуска команд)

## Структура проекта

- `src/test/java/tests` — тестовые классы (`ConsultantHappyPathTest`).
- `src/test/java/pages` — Page Object:
   - `HomePage` — главная страница и переход в быстрый поиск.
   - `SearchPage` — ввод запроса, нажатие «Найти», ожидание выдачи.
   - `ResultsPage` — поиск и открытие документа по названию, получение полного названия из выдачи.
   - `DocumentPage` — работа со страницей документа: поиск текста, клик по ссылке на абзац, проверки.
- `src/test/java/utils` — утилиты:
   - `Config` — константы: `BASE_URL`, `SEARCH_QUERY`, `TARGET_DOC_TITLE`.
- `src/test/resources` — конфигурационные файлы:
   - `testng.xml` — набор тестов TestNG с подключённым Allure‑listener.
   - `allure.properties` — каталог результатов Allure.

## Конфигурация

Основные параметры вынесены в `utils.Config`:

- `BASE_URL` — `http://www.consultant.ru/cons/`
- `SEARCH_QUERY` — `Налоговый часть`
- `TARGET_DOC_TITLE` — `Налоговый кодекс Российской Федерации (часть вторая)`

Таймауты и ожидания:

- Общее явное ожидание в тестах: 25 секунд (`Duration.ofSeconds(25)`).
- Для стабильной отрисовки динамических элементов используются дополнительные паузы:
   - 2 секунды после появления выдачи в `SearchPage.waitForResults()`.
   - 3 секунды после перехода по ссылке на абзац и перед снятием скриншота в тесте.

## Запуск тестов (PowerShell)

Тесты стабильно запускаются из PowerShell последовательным выполнением команд:

1. Запустить тесты:

   ```powershell
   mvn clean test
   ```

2. Собрать Allure‑отчёт (явное указание версии плагина):

   ```powershell
   mvn io.qameta.allure:allure-maven:2.15.0:report
   ```

3. Открыть отчёт в браузере:

   ```powershell
   mvn io.qameta.allure:allure-maven:2.15.0:serve
   ```

При необходимости можно использовать и короткие формы команд (через конфигурацию плагина в `pom.xml`):

```powershell
mvn allure:report
mvn allure:serve
```

но для максимальной стабильности рекомендуется явный вариант с указанием полной координаты плагина `io.qameta.allure:allure-maven:2.15.0`.

## Что проверяет тест

1. Открывается главная страница КонсультантПлюс.
2. Осуществляется переход в «Быстрый поиск».
3. Вводится запрос «Налоговый часть» и нажимается кнопка «Найти».
4. В результатах поиска:
   - ожидается ссылка на документ «Налоговый кодекс РФ (часть вторая)»;
   - сохраняется полное название документа из выдачи;
   - название нормализуется (удаляются кавычки, лишние пробелы, неразрывные пробелы);
   - проверяется, что нормализованное название начинается с ожидаемого `TARGET_DOC_TITLE`;
   - после открытия документа проверяется, что в строке поиска отображается исходный запрос `SEARCH_QUERY`.
5. В тексте документа:
   - находится фраза «абзаце первом пункта 1»;
   - выполняется клик по ссылке «абзаце первом пункта 1»;
   - ожидается визуальная отрисовка целевого абзаца и жёлтой стрелки.
6. Делается скриншот пункта 1 статьи 145 после перехода по ссылке и прикрепляется к Allure‑отчёту.
7. В отчёт добавляются:
   - текстовое вложение с проверками (полное и нормализованное название, ожидаемое начало, запрос в строке поиска);
   - текстовое вложение с описанием ожидаемого результата (жёлтая стрелка, текст абзаца).
8. При падении теста:
   - создаётся скриншот ошибки в `target/screenshots`;
   - скриншот прикрепляется к Allure‑отчёту.

## Примечания

- Если сайт запросит капчу — пройти её вручную, затем повторить запуск теста.
- При необходимости можно увеличить общий таймаут в `ConsultantHappyPathTest` (поле `TIMEOUT`).
- Локаторы в Page Object могут требовать уточнения при изменении вёрстки consultant.ru:
   - поле поиска: `input.x-search-box__input`;
   - кнопка «Найти»: `//button[normalize-space(.)='Найти']`;
   - появление результатов: `//a[contains(., 'Налоговый')]`;
   - поиск документа по названию: динамический XPath, формируемый в `ResultsPage.documentLink(String title)`.
